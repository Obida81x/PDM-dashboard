# PDM — لوحة التحكم (Dashboard)

لوحة تحكم **منفصلة تماماً** عن الموقع، واجهة أمامية فقط (React + Vite + JavaScript + react-router-dom — نفس تقنيات الموقع، ونفس الألوان والخطوط).
ما فيها أي باك إند: كل الاتصال بالبيانات يمرّ من ملف واحد `src/services/api.js`.

## التشغيل
```bash
npm install
npm run dev        # http://localhost:5174
npm run build
```
بدون ملف `.env` تشتغل اللوحة بـ **وضع تجريبي** (البيانات محفوظة في متصفحك) عشان تجرّب كل شي:
المستخدم `admin` — كلمة المرور `admin123`.

## ماذا تتحكم اللوحة؟
| الصفحة | تتحكم بـ |
|---|---|
| نظرة عامة | ملخص الزيارات والرسائل والمشاريع + اختصارات |
| الإحصائيات والزيارات | زيارات، زوار فريدون، مشاهدات، مصادر، أجهزة، دول، لغات، متصفحات، ساعات الذروة |
| السلايدر | الصور المتحركة بالواجهة الرئيسية: إضافة/حذف/ترتيب، السرعة، نوع الانتقال، النقاط والأسهم، معاينة حيّة |
| النصوص والأقسام | **كل نص** بالموقع (عربي + إنجليزي): القائمة، الواجهة، الخدمات، الأعمال، من نحن، التواصل، CTA، الفوتر، نصوص صفحة المشروع و404، والأرقام المتحركة |
| معلومات التواصل | الإيميل، الهاتف، إيميل استقبال النموذج، رابط الخريطة، السوشيال |
| المشاريع | إضافة / تعديل / حذف / نسخ / إخفاء / ترتيب، صورة الغلاف والمعرض، النتائج، الأدوات، دراسة الحالة المميزة |
| قصتنا | المقدمة، كيف بدأنا، الاقتباس، **التسلسل الزمني** (إضافة/حذف محطات)، القيم، الأرقام، الرؤية |
| الرسائل | صندوق رسائل نموذج التواصل (قراءة، رد بالإيميل، حذف) |
| مكتبة الوسائط | رفع وحذف كل الصور |
| الحسابات | مستخدمو اللوحة وصلاحياتهم (مالك / محرر / مشاهد) |
| الإعدادات | اسم الموقع، الشعار، Favicon، اللون الأساسي، اللغة والمظهر الافتراضيين، SEO، وضع الصيانة، التتبع، تغيير كلمة المرور، نسخ احتياطي |

> لو أضفت نصاً جديداً بالموقع لاحقاً: أضف حقله في `src/data/schema.js` (سطر واحد) وبيظهر بالوحة تلقائياً.

## ربط الباك إند
1. أنشئ `.env` :  `VITE_API_URL=https://your-backend.com/api`
2. كل الطلبات ترسل `Authorization: Bearer <token>` (ما عدا login). عند `401` ترجع اللوحة لصفحة الدخول.

| Method | Path | الوصف |
|---|---|---|
| POST | `/auth/login` | `{username,password}` → `{token, user}` |
| GET | `/auth/me` | المستخدم الحالي |
| POST | `/auth/change-password` | `{current,next}` |
| GET / PUT | `/site` | مستند الموقع كامل (انظر الشكل تحت). PUT يستبدله |
| POST | `/site/reset` | إعادة المحتوى للأصل |
| GET / POST | `/projects` | قائمة المشاريع (مرتبة بـ `order`) / إضافة |
| PUT / DELETE | `/projects/:id` | تعديل / حذف |
| PUT | `/projects/order` | `{ids:[...]}` ترتيب جديد |
| GET | `/messages` | الرسائل (الأحدث أولاً) |
| PATCH / DELETE | `/messages/:id` | `{read:true}` / حذف |
| GET / POST | `/media` | المكتبة / رفع `multipart` حقل `file` → `{id,url,name,size,createdAt}` |
| DELETE | `/media/:id` | حذف |
| GET / POST | `/users` | الحسابات / إضافة |
| PUT / DELETE | `/users/:id` | تعديل / حذف (`password` اختياري عند التعديل) |
| GET | `/analytics?range=7\|30\|90` | الإحصائيات |

الأخطاء: ارجع `{ "message": "نص عربي" }` مع كود HTTP مناسب وبتظهر كما هي للمستخدم.

### شكل `/site`
`texts` (كل نص `{ar,en}`، نفس مفاتيح `translations.js` بالموقع) · `numbers` · `contact` · `slider` · `settings` · `story` (نفس شكل `STORY` في `cms.js`).
أسهل طريقة تشوف الشكل الكامل: افتح `src/data/defaults.json` (هذا هو محتوى الموقع الحالي بنفس الشكل).

### شكل `/projects/:id`
نفس عناصر `PROJECTS` في `cms.js` + الحقول: `id`, `order`, `published` (false = مسودة، لا يُرجعها API العام)، `cover` (رابط صورة الغلاف).
`gallery` عناصره إما رابط صورة أو اسم رسمة مدمجة (`laptop`, `phones`, `dash`, `finance`, `brand`, `app`) — والموقع أصلاً يدعم الاثنين عبر `Media.jsx`.

### شكل `/analytics`
شوف `src/services/analytics.js` (الدالة `mockAnalytics`) — نفس الشكل المطلوب بالضبط:
`totals{visits,visitors,pageviews,avgDuration,bounceRate,newVisitorsRate,online,deltas}`, `daily[{date,visits,visitors,pageviews}]`, `topPages`, `sources`, `devices`, `browsers`, `countries`, `languages`, `hours[24]`.
الباك إند بيجمع الزيارات من الموقع (يضيف الموقع طلب بسيط `POST /track {path, lang, referrer}` عند كل تنقل — ذلك يتم بالموقع نفسه لاحقاً، وهذه اللوحة فقط تعرض الأرقام).

## ملاحظات مهمة
- **السلايدر**: اسمه بالمصطلح *Hero Slider / Carousel*. الموقع الحالي يعرض صورة ثابتة، فلازم ينقرأ `slider` من `GET /site` (فيه `slides[{image,alt,title,subtitle,active}]`, `interval`, `transition`, `autoplay`…).
- بما أنك ما بدك أي تعديل بالموقع الآن: الموقع حالياً يقرأ المشاريع والقصة فقط من API. باقي النصوص (`translations.js`) لازم يقرأها من `/site` (عبر `localize`) لما يجي دور الربط — اللوحة جاهزة وتحفظها بنفس الشكل.
- الوضع التجريبي يخزّن الصور مصغّرة داخل `localStorage` (حد ~5MB). مع الباك إند الصور بتنرفع للسيرفر.
- كلمات المرور بالوضع التجريبي نص عادي للتجربة فقط. مع الباك إند خزّنها مشفّرة (bcrypt/argon2) ولا ترجعها بأي response.
- الصلاحيات (`owner/editor/viewer`) تُحفظ بالحساب، لكن **فرضها (من يقدر يعدّل ماذا) مسؤولية الباك إند**.
- اللوحة بالعربية RTL (مع وضع داكن/فاتح مثل الموقع). `noindex` مفعّل في `index.html`.
